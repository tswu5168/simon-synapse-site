# 首頁標語與大字切換移除設計

## 目標

首頁主標語改為「創意遇見 AI，未來由此展開」，並移除頁首的「切換為大字」控制項。網站維持目前預設的易讀字級，不縮小文字，也不改變既有視覺風格、導覽結構與四個核心作品。

## 核准文案

- 中文主標語：`創意遇見 AI，未來由此展開`
- 英文眉題：維持 `Simon Synapse · Human ideas × AI systems`

中文標語使用「AI／展開」的近似韻腳，保留創意、AI 與未來三個品牌核心，同時避免收益承諾。

## 變更範圍

1. 更新中央網站設定中的品牌標語，使首頁主標題、頁尾與「關於」頁自動使用新文案。
2. 更新品牌介紹文章中原本提到「用 AI 實現財富自由」的段落與摘要，改以新標語說明創意、實作、驗證與持續改進。
3. 從頁首移除大字切換元件的引用與畫面控制項。
4. 刪除不再使用的大字切換元件、瀏覽器儲存邏輯及專用端對端測試。
5. 移除只服務該切換功能的 `data-font-scale="large"` 樣式；保留全站 `--font-scale: 1` 與目前所有預設字級計算。
6. 更新品牌設定與首頁閱讀順序測試，並新增頁首不再顯示大字切換按鈕的驗收。

## 易讀性原則

- 行動裝置本文預設維持 `1.125rem`。
- 桌面本文預設維持 `1.25rem`。
- 標題仍使用既有響應式放大規則。
- 保留瀏覽器原生縮放、鍵盤操作、焦點樣式與無障礙重排能力。
- 移除控制項後，頁首導覽靠右排列，不保留空白佔位。

## 不在本次範圍

- 不重新設計首頁背景、色彩、動態效果或按鈕。
- 不修改四個核心作品的順序、內容與連結。
- 不啟用 AdSense，也不送出 AdSense 重新審查。
- 不修改 Cloudflare 網域與其他子網站。

## 測試與驗收

1. 測試先確認舊標語仍存在、頁首仍有大字切換按鈕，因此在新需求下失敗。
2. 完成最小修改後，首頁只顯示新標語，且全站原始碼不再包含舊標語。
3. 頁首不再存在「切換為大字」或「切換為標準字」按鈕，也不再載入對應腳本。
4. Astro 檢查、單元測試、正式版建置與 Chromium 端對端測試全部通過。
5. 發布後 `https://simonsynapse.net/` 為 HTTP 200，公開首頁顯示新標語且沒有大字切換按鈕。
